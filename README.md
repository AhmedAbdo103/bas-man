# باص مان 🚌

الحلم شاص والواقع فوق باص

## بناء APK عبر GitHub Actions
1. أنشئ مستودع GitHub جديداً وارفع محتويات هذا المجلد إليه.
2. افتح تبويب Actions وشغّل Build Bas Man APK (أو انتظر البناء بعد push).
3. بعد نجاح البناء افتح نتيجة التشغيل ثم Artifacts ونزّل bas-man-debug-apk.zip.
4. فك الضغط وثبّت app-debug.apk على هاتف Android.

هذه نسخة تجريبية. البيانات تحفظ محلياً على الجهاز؛ احتفظ بنسخ احتياطية منتظمة.
